# Simple Discord Bot

A minimal Discord bot made with Python and `discord.py`.

The bot only connects to Discord and stays online.

---

## Features

- Simple setup
- Lightweight
- Easy to expand later
- Beginner friendly

---

## Requirements

- Python 3.8+
- A Discord Bot Token
